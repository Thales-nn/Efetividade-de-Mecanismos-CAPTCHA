# Dashboard em Python para apresentação do TCC

Este diretório contém uma versão standalone do dashboard, sem menu lateral e com dois gráficos de tempo por tentativa.

## Como executar

```bash
cd dashboard
python dashboard.py
```

Depois, abra o arquivo `dashboard.html` gerado no navegador.

## Observação

Os dados usados aqui são de exemplo para apresentação do trabalho. Quando você tiver os valores reais, basta substituir os arrays `BOT_2_TIMES` e `HUMAN_TIMES` no arquivo `dashboard.py`.
